# 07 検証と出力

[INDEX](KiCad_MCP_ルール.md)

## ルール

1. 変更のたびに ERC と DRC（`--schematic-parity` 付き）を実行し、**エラー 0、未接続 0、回路図との差分 0** にする。残す警告は理由を説明できるものだけにする。
2. 回路図を変えたら、**変更前後のネットリストを比べ**、意図した差分だけであることを確認する。
3. 基板を自動で編集したら、**配線・ビア・部品位置が意図せず変わっていないか**、変更前の基板と比べる。
4. 結果は画像にして目で確認し、ユーザーに見せる。
5. 出力は、ガーバー＋ドリル、BOM、基板と回路図の PDF。完成品を OneDrive のプロジェクトへコピーし、旧版は `old_<内容>\` に残す。
6. JLCPCB Tools を使う場合は、基板を変えたら**製造ファイルを作り直す**。
7. 発注前に確認する: 全部品のフットプリントがデータシートと照合済み（→ [09_フットプリント](09_フットプリント.md)）、部品表（型番・在庫）と BOM が一致、設計ルールが最新（→ [02_設計ルール_JLCPCB](02_設計ルール_JLCPCB.md)）、面付けの有無。

## 手順

```
kicad-cli sch erc --severity-error -o erc.rpt <sch>
kicad-cli pcb drc --severity-all --schematic-parity -o drc.rpt <pcb>
kicad-cli sch export netlist --format kicadxml -o netlist.xml <sch>
kicad-cli pcb export pdf --layers "F.Cu,Edge.Cuts" --mode-single -o out.pdf <pcb>
kicad-cli pcb export gerbers -o fab/gerber/ <pcb>
kicad-cli pcb export drill -o fab/gerber/ <pcb>
kicad-cli sch export bom -o fab/bom.csv <sch>
```

- ネットリストの比較: 両方の `netlist.xml` からネット名 → (部品, ピン) の集合を作って比べる（`unconnected-` で始まるネットは除く）。部品を置き換えた場合はピン番号の読み替え表を通す。
- 基板の比較: `.kicad_pcb` から segment・via・footprint の座標を抜き出して比べる。
- 画像: PDF を `pymupdf` で PNG にし、必要な範囲を切り出して拡大する。

## 理由（過去の失敗）

- 1: `--schematic-parity` を付けずに済ませていた間、ネット名の「/」違い・BOM 除外・欄の違い・1 ピンだけの未接続ネットの付け忘れに気付かなかった。
- 3: 補修後の DRC で、配線の端がパッドに届かない未接続が見つかった。
- 6: 基板を直した後も、JLCPCB Tools の製造ファイルが古いままだった。
- 7: 電解コンデンサの型（アキシャル品）とフットプリント（ラジアル）が違うまま部品表を作っていた。
