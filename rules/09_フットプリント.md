# 09 フットプリント

[INDEX](KiCad_MCP_ルール.md)

## ルール

1. 部品は **KiCad 標準ライブラリ ＞ easyeda2kicad（LCSC/EasyEDA） ＞ 自作** の順に探し、上で見つかればそれを使う。汎用品（抵抗・コンデンサ・TO-92・DIP・ピンソケット・タクトスイッチなど）はまず KiCad 標準。
2. どれを使う場合も、**購入する品のデータシートと照合してから**基板に載せる。照合する項目:

| 項目 | 見る点 |
|---|---|
| リード形状 | ラジアル／アキシャル、足の曲げ（例: TO-92 のテープ品は 2.54 mm に曲げ済み、ばら品はまっすぐ 1.27 mm）|
| 足の間隔・配置 | ピッチ、列間隔、**一直線か三角配置か** |
| ピン番号と機能 | データシートのピン表、フットプリントのパッド番号、回路図のピン番号が一致するか |
| 図の向き | 足の図が**上面図か底面図か**（外形の切り欠きの位置で判断）。底面図なら左右を反転して読む |
| 外形 | 本体の大きさ・厚み（隣の部品と当たらないか）|
| 穴径 | リード径＋0.2〜0.4 mm（推奨穴径があればそれ）|
| 極性表示 | ルール 6 を満たすか |

3. **部品表の型番を変えたら、必ずフットプリントも照合し直す。**
4. ソケット経由で挿す部品は、**ソケットのピン番号と部品の足の対応**も確認する。どの向きで挿しても結線が合わない組み合わせは使わない。
5. 自作は次の順で行う: データシートを読む → 上面図で座標を書き出す → `.kicad_mod` を作る → **数値で検証** → **画像で検証** → 基板に反映して DRC。不明な点（上面図か底面図か等）は `descr` に書き、影響を評価する。
6. **極性・向きの表示**: 1 番ピンのパッドは角形にし、シルクの外形の 1 番側の角を落とす（切り欠き）。センサなどは**実物の外形の切り欠きと同じ角**に切り欠きを入れる。有極性コンデンサは＋側、TO-92 は平らな面、IC はノッチ、表示器は「1」も書く。
7. 自作フットプリントは、パッド（1 番は角形）、F.Fab に実寸の外形、F.SilkS にパッドに掛からない外形と極性表示、F.CrtYd に外形＋0.25 mm を入れ、`descr` に参照したデータシートと寸法の根拠を書く。
8. 取り込んだ部品・自作した部品は `MyParts` に入れ、プロジェクトには使う分だけコピーする（→ [03_回路図とライブラリ](03_回路図とライブラリ.md)）。
9. KiCad 標準に近いものがあり寸法を 1 か所だけ変えるとき（穴径など）は、標準品を複製して変えた所と元の名前を `descr` に書く（例: `TestPoint_THTPad_D2.0mm_Drill0.85mm`）。
10. 両面に同じランドが要るとき（ワニ口用の GND ランドなど）は、同じ番号の SMD パッドを F.Cu と B.Cu に 1 つずつ置き、裏のシルクは `justify mirror` で入れる。ベタには全面接続（`SetLocalZoneConnection(FULL)`）。

## 手順

| 作業 | 方法 |
|---|---|
| KiCad 標準を探す | `C:\Program Files\KiCad\10.0\share\kicad\footprints\*.pretty` をパッケージ名・型番で探す |
| LCSC 番号を調べる | LCSC のサイトで型番検索（結果ページへ移動した後、本文から `C\d+` を拾う）|
| easyeda2kicad | `python -m easyeda2kicad --full --lcsc_id=<C番号> --output "C:\Users\<user>\Documents\KiCad\MyParts\MyParts"`。プロジェクトへコピーしたら 3D モデルのパスを `${KIPRJMOD}` 基準に直し、シンボルは `kicad-cli sym upgrade` で新形式にする |
| データシート | 販売店（秋月など）の商品ページの「データシート」リンク。許可を取って `curl` で取得し、`pymupdf` で必要なページを拡大した PNG にして読む |
| 自作 | `.kicad_mod` をテキストで書き、`kicad-cli fp upgrade` で形式をそろえる |
| 数値検証 | pcbnew の `FootprintLoad` でパッド座標・大きさ・穴径、F.Fab の外形を取り、データシートの値と並べて表示する |
| 画像検証 | 基板に置いた状態を PDF → PNG にして、向き・極性表示を目で確かめる。切り欠きに一番近いパッドが、データシートの切り欠き側のピンか計算でも確かめる |
| 基板の差し替え | `pcb_fp_update.py`（位置・向き・ネット・回路図との対応を引き継ぐ。ネットは回路図のネットリストから付ける）|

## 理由（過去の失敗: 2026-10-10 の照合で見つかったもの）

| 部品 | 失敗 | 対処 |
|---|---|---|
| 47μF 電解 | ラジアル用フットプリントに、アキシャル品（ニチコン PC）を部品表に載せていた（ルール 2・3）| ラジアル品（ルビコン PX、端子間 2.0 mm）に替え、フットプリントも P2.00 に |
| RPR-220（センサ） | 2×2 の汎用ソケット（2.54 mm）に挿す設計で、どの向きで挿しても結線が合わなかった。実物は 2.8×2.5 mm、KiCad の PinSocket は番号が左右反転（ルール 2・4）| easyeda2kicad の RPR-220（切り欠き付き）に替え、ネットをピン表（1=A, 2=K, 3=E, 4=C）に合わせた |
| GF063P（半固定） | データシートを見ずに足を一直線・2.5 mm と仮定していた（ルール 5）| データシートどおり三角配置（1–3 が 5 mm、2 番は中央から 2.5 mm）で作り直した |
| 2SC1815 | easyeda2kicad の TO-92 はテープ品向けの 2.54 mm で、秋月のばら品（1.27 mm）と合わない（ルール 1・2）| KiCad 標準の `TO-92_Inline` を使った |
| HDSP-K123 | LCSC にあるが EasyEDA の API にデータがなく、easyeda2kicad が失敗した | 自作（ピン表・寸法を照合済み）|

- 図の向きの判断: RPR-220 は、上面図の切り欠きが右上、足の図では右下にあった → 足の図は底面図。
- 三角配置の半固定抵抗は、180° 回して挿すと 1 番と 3 番が入れ替わるだけ（回す向きが逆になる）。図の解釈が不明でも物理的には挿せる。
- easyeda2kicad のフットプリントはパッドが小さめのことがある（例: 電解コンデンサの穴 0.7 mm・パッド 1.1 mm）。KiCad 標準に同じ形があれば標準を使う（ルール 1）。
