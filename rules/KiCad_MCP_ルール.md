## 特に重要なルール

1. 作業はローカル（`Documents\KiCad_work`）で行い、完成品だけ OneDrive へコピーする。作業前に OneDrive 側の変更を確認する（01）。
2. 設計ルールは JLCPCB 推奨（02）。
3. 部品は **KiCad 標準 ＞ easyeda2kicad ＞ 自作** の順で選び、**購入品のデータシートと照合してから**使う（09）。
4. 配線が通るかは配置とピン割り当てで決まる。混み具合を見て複数案を並行して試す（04）。未接続 1〜3 本は手動で仕上げる（05）。
5. 変更のたびに ERC・DRC（回路図との照合つき）でエラー 0・未接続 0・差分 0 にし、変更前後を比較する（07）。
