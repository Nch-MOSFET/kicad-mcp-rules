# 03 回路図とライブラリ

[INDEX](KiCad_MCP_ルール.md)

## ルール

1. 回路図は**ネットラベルだけで接続**する（ワイヤは引かない）。
2. 未使用ピンには `no_connect` を付け、ERC をエラー 0 にする。
3. 回路図は**機能ブロックごとに枠とタイトル**を付けて並べる（A3）。抵抗・コンデンサは横向き、ラベルはピンの外向きにする。
4. **部品ライブラリの正本は `C:\Users\<user>\Documents\KiCad\MyParts`**（`MyParts.kicad_sym` / `MyParts.pretty` / `MyParts.3dshapes`）。取り込んだ部品・自作した部品は必ずここにも入れる。
5. **プロジェクトには使う部品だけを `lib\<名前>\` にコピーし、プロジェクトのライブラリ表（`fp-lib-table`、`sym-lib-table`）に `${KIPRJMOD}` 基準で登録する。** 3D モデルのパスも `${KIPRJMOD}` 基準にする（OneDrive 上でもプロジェクト単体で開けるようにするため）。
6. ライブラリを追加したら、ライブラリ表への登録を忘れない。
7. 実在のモジュール（マイコンモジュール等）は、メーカー提供のライブラリか公式の寸法図から作ったものを使う（→ [09_フットプリント](09_フットプリント.md)）。
8. 部品の置き換え・回路図の整理・GPIO の入れ替えの前後で、**ネットリストを比べて意図した差分だけであることを確認する**（→ [07_検証と出力](07_検証と出力.md)）。
9. GPIO を入れ替えたら、ピン表（`gpio_pinmap.json`）に従って回路図のラベルも書き換え、ファームウェア用のピン表を設計メモに残す。ADC を入れ替えたときは、ファームの ADC チャンネル番号（RP2040 は GPIO 番号 − 26）も合わせる。ラベルの書き換えは `revf_pinmap_sch.py` が手本。

## 手順

- ピン座標 ＝ シンボル位置 ＋ ライブラリのピン座標（Y は反転）。回転したシンボルは回転行列を掛ける。
- 回路図の整理: `relayout.py`（位置表 `layout_map.py`）。
- 外部ライブラリの取り込み（Library Loader の zip など）:
  1. 必要なフォルダ（`KiCad\`、`3D\`）だけを取り出す。
  2. `kicad-cli sym upgrade` / `kicad-cli fp upgrade` で KiCad 10 形式にする。
  3. シンボルの Footprint 欄を `ライブラリ名:フットプリント名` にする。
  4. 回路図の部品を置き換える（手本: `swap_rp.py`、`sch_fp_update.py`。旧シンボルのラベルから新シンボルのピンへネットを移す）。
- easyeda2kicad で取り込む場合は [09_フットプリント](09_フットプリント.md)。

## 理由（過去の失敗）

- 3: ラベルだけの回路図は、整理しないと読めなかった。
- 8: 置き換え・整理のたびにネットリストを比較して、接続の誤りがないことを確かめてきた（置き換えはピン番号の読み替え表を通して比較）。
- 回転したシンボルでは、参照名・値の文字角度がシンボルに対する相対角になる（90° 回転した抵抗の文字を横書きにするには角度 90）。
- 回路図のネット名は「/NAME」（シート名付き）。基板側を「NAME」で作ると、回路図との照合で全ネットが不一致になった（→ [07_検証と出力](07_検証と出力.md)）。
