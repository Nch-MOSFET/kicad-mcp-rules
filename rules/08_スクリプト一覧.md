# 08 スクリプト一覧

[INDEX](KiCad_MCP_ルール.md)

## ルール

1. スクリプトは作業フォルダ `C:\Users\<user>\Documents\KiCad_work` で実行し、完成時にプロジェクトフォルダ（OneDrive）へもコピーする。
2. 基板系は KiCad 付属 Python、回路図のテキスト編集系は通常の Python で実行する。
3. **基板は毎回ネットリストから新規生成する。** 既存基板の再利用は、部品位置の読み込み（`FROMBOARD`）と、差し替え・補修などの部分的な編集に限る。
4. スクリプトを書き換えたら、構文チェック（`ast.parse`）をしてから実行する。一括置換（`sed` など）は、対象を特定できる文字列にだけ使う。
5. 一回限りの編集スクリプトも、手本として残し、プロジェクトへコピーする。

## 手順

| スクリプト | 役割 | 使い方 |
|---|---|---|
| `build_board.py` | ネットリストから基板を新規生成 → 配置 → 配線 → GND ベタ | `python build_board.py <netlist.xml> <out.kicad_pcb> <プロジェクト>`（環境変数 `VAR` `SEED` `MARGIN` `NIT` `CONG` `PINSWAP` `ATT`）|
| `place_v2_block.py` | 配置部分（焼きなまし、混み具合、回転、GPIO 入れ替え）| `build_board.py` から読み込まれる。`FROMBOARD=<基板>` で既存基板の配置を再利用 |
| `place_only.py` | 配置だけを試す | 環境変数は `build_board.py` と同じ |
| `fixup2.py` | 失敗したネットだけを既存配線の上に引く | `python fixup2.py <出力フォルダ>` → `fixed.kicad_pcb` |
| `silk.py` | シルクの整理と回路図との差分の修正 | `python silk.py <in> <out> <netlist.xml> <pinmap.json>` |
| `relayout.py` ＋ `layout_map.py` | 回路図を機能ブロックごとに並べ直す | `python relayout.py <in.kicad_sch> <out.kicad_sch>` |
| `pcb_fp_update.py` | 基板の部品を新しいフットプリントに差し替え（位置・向き・ネット・回路図との対応を引き継ぐ）| `python pcb_fp_update.py <in> <out> <netlist.xml>`（手本）|
| `sch_fp_update.py` | 回路図のシンボルを差し替え、テストポイントを追加 | 一回限り（手本）|
| `swap_rp.py` | 回路図の 2 つのコネクタを 1 つのモジュールのシンボルに置き換え | 一回限り（手本）|
| `swap_c1.py` | 基板の部品を別のフットプリントに差し替え（面付けの複数枚にも対応）| `python swap_c1.py <board>` |
| `remove_oled.py` / `remove_oled_pcb.py` | 部品の削除（回路図／基板。基板は不要になった配線も消す）| 一回限り（手本）|
| `addlabels.py` | 回路図のピンにネットラベルを付ける | 一回限り（手本）|
| `build_revF.py` ＋ `place_revF.py` | 版を上げるときの基板の新規生成（大物は `FIXEDFROM` の基板の位置に固定、基板の端は強く禁止）| 血管年齢測定器 Rev.F（手本）|
| `fixup_revF.py` | `fixup2.py` の Rev.F 版（作業フォルダの `netlist.xml` と `build_revF.py` を使う）| `python fixup_revF.py <フォルダ>` |
| `eval_revF.py` | 配置の評価（部品の外形どうしの最小間隔、1.7／1.4 mm 未満の組）| `python eval_revF.py <board> ...` |
| `add_track.py` | 直線の配線を手で足す（自動で通らなかった 1 本など）| `python add_track.py <in> <out> <net> F|B <幅> x0,y0 x1,y1 ...` |
| `revf_renumber.py` | 部品番号を役割の順に振り直す（2 段階で置換、対応表 JSON を出力）| 手本 |
| `revf_pinmap_sch.py` | 基板で入れ替えた GPIO（pinmap.json）を回路図の U2 のラベルに反映 | `python revf_pinmap_sch.py <in> <out> <pinmap.json>` |
| `fix_back_tp.py` | 裏面のテストポイント番号が基板からはみ出すとき反対側へ移す | 手本 |

- 所要時間の目安: 配置 15〜20 分、配線 1 試行 10 分。複数条件を並行実行し、ログの `FAILED:` 行で比べる。

## 理由（過去の失敗）

- 3: 修正済みの基板を読み直して同じスクリプトを再実行すると SWIG エラーが出た。
- 4: `sed` の一括置換で意図しない箇所（`range(2)` など）まで書き換わり、スクリプトが壊れた。
