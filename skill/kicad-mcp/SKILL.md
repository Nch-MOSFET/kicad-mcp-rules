# KiCad MCP 作業の前に読むもの

KiCad の作業（MCP ツールの呼び出し、kicad-cli、自作スクリプトのどれでも）を始める前に、**ユーザーの KiCad MCP 利用ルール集を読んでから**進める。ルール集が正本で、このスキルはその入口だけを示す。内容をここに写さない。

## 読む順番

ルール集の場所: このリポジトリの `rules/`（置いた場所に合わせて書き換える）

1. `KiCad_MCP_ルール.md`（INDEX。特に重要なルールの一覧）
2. `01_作業環境とツール.md`（作業フォルダ、保存場所、MCP の使い方、ダウンロードは許可を取る）
3. `02_設計ルール_JLCPCB.md`（設計ルールの既定値とテンプレート）
4. `03_回路図とライブラリ.md`（ネットラベル方式、ライブラリの置き場所）
5. `09_フットプリント.md`（部品の探す順番、データシートとの照合）
6. 作業の段階に応じて `04_配置.md`、`05_配線.md`、`06_シルク.md`、`07_検証と出力.md`、`08_スクリプト一覧.md`

入口の README: このリポジトリの `README.md`

## 進め方

- 1〜5 はどの作業でも最初に全部読む。6 はその段階に入る前に読む。
- ルールとユーザーのその場の指示が食い違うときは、ユーザーの指示に従い、どのルールの例外かをユーザーに伝える（例: シルクに部品の値を入れる指示は 06 の例外）。
- ルール集にない新しい失敗や決まりごとが出たら、作業の終わりにルール集へ追記するか、ユーザーに追記を提案する。
